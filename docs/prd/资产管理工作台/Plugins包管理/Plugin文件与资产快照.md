# Plugin文件与资产快照

类型：概念（Concept） · 状态：当前实现反推 · 核对日期：2026-10-18

## 功能描述

查看编辑完整包文件，并识别包内资产或放入全库资产的独立快照。

## 定位

所属功能包：[[docs/prd/资产管理工作台/Plugins包管理|Plugins包管理]]。本节点为原子能力，引用依赖与层级子节点分开维护。

- [[docs/prd/资产管理工作台/Plugins包管理/Plugin文件与资产快照|Plugin文件与资产快照]] [C] ●

## 业务规则与约束

- 文件可文本编辑、上传文件/目录和删除；在线文本最多 2000000 字节，二进制通过上传替换。
- 一次保存 1–1000 个文件且最多 12000000 字节，版本说明去空白后至少 3 字、原文最多 200 字；新文件被忽略时拒绝保存。
- 识别原生项目与插件的 Skills、Rules、Agents、Hooks；也可把全库资产放入 .plugin-assets 下的独立快照。
- 快照不随原资产更新、不自动回写原资产；项目和审查配置不作为包内资产，不复制密钥和本机环境变量。
- 包文件路径不得越界或涉及 .git/链接；修改他人包前必须切换自己的分支。

## 交互流程和细节

**前置条件**：应用已启动，用户进入上述功能入口；涉及已有资产时先选择资产。其余前置能力见下方引用。

1. 进入 Plugin 的文件页查看内容，编辑或上传替换。
2. 填写说明保存版本；资产页查看识别结果或选择放入已有资产快照。
3. 需要修改快照时编辑包内容并保存包版本。

**反馈与结果**：原资产修改后包内快照保持原值。

## 数据范围

包内任意普通文件、识别出的原生资产及全库资产快照。

## 边界情况与异常处理

- 二进制不当作文本强行保存；文件过大提示不能在线编辑。
- 受保护分支、非法文件路径或忽略规则阻止保存。

## 验收条件

- 原资产修改后包内快照保持原值。
- 未满足校验的文件批次不先写入其中一部分。
