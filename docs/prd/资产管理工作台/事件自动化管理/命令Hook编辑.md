# 命令Hook编辑

类型：概念（Concept） · 状态：当前实现反推 · 核对日期：2026-10-18

## 功能描述

配置目标软件的事件、匹配条件、执行环境和脚本。

## 定位

所属功能包：[[docs/prd/资产管理工作台/事件自动化管理|事件自动化管理]]。本节点为原子能力，引用依赖与层级子节点分开维护。

- [[docs/prd/资产管理工作台/事件自动化管理/命令Hook编辑|命令Hook编辑]] [C] ●

## 业务规则与约束

- 仅管理项目级 command Hooks，运行环境为 Node.js、Python、PowerShell 或 Bash。
- 事件须适用于目标软件；匹配条件最长 500 字符，非空且非 * 时需为合法正则，事件不支持匹配时必须留空。
- 超时为 1–600 秒整数；Codex SessionEnd 只能同步，SessionEnd 与 Interrupt 最多 3 秒。
- 脚本仅支持文本，最多 50 个文件且合计最多 1000000 字节；入口需存在、非空且后缀匹配运行环境。
- 保存不执行脚本；异步脚本的控制返回不能阻止当前操作。Codex 原生状态提示和上下文长度选项可保留。

## 交互流程和细节

**前置条件**：应用已启动，用户进入上述功能入口；涉及已有资产时先选择资产。其余前置能力见下方引用。

1. 进入单个 Hook，选择目标软件与事件。
2. 编辑匹配条件、同步/异步、超时、运行环境和脚本入口。
3. 检查与预览，填写说明保存。

**反馈与结果**：Codex SessionEnd 设置异步时校验失败。

## 数据范围

Hook 执行设置、入口和文本脚本。

## 边界情况与异常处理

- 无效事件、正则、入口或超时阻止保存。
- 不支持用户级、HTTP、MCP、prompt、agent 类型的 Hook 管理。

## 验收条件

- Codex SessionEnd 设置异步时校验失败。
- 普通脚本保存后不产生执行输出。
