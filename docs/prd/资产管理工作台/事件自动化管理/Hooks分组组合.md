# Hooks分组组合

类型：概念（Concept） · 状态：当前实现反推 · 核对日期：2026-10-18

## 功能描述

把同一软件、共同用途的多个 Hook 组织为可整体应用的组。

## 定位

所属功能包：[[docs/prd/资产管理工作台/事件自动化管理|事件自动化管理]]。本节点为原子能力，引用依赖与层级子节点分开维护。

- [[docs/prd/资产管理工作台/事件自动化管理/Hooks分组组合|Hooks分组组合]] [C] ●

## 业务规则与约束

- 组需填写名称、目标软件和共同用途；包含 1–100 个不同现有 Hook。
- 成员必须适用于组的软件；可填最长 2000 字符的成员作用。
- 组引用成员，不复制脚本、不绑定模型、不定义事件执行顺序。
- 组版本和成员版本分别记录；取消某个引用来源后，仍被其他来源引用的 Hook 保留。

## 交互流程和细节

**前置条件**：应用已启动，用户进入上述功能入口；涉及已有资产时先选择资产。其余前置能力见下方引用。

1. 进入 Hooks 组，填写共同用途和目标软件。
2. 选择成员并补充作用，保存版本。
3. 在 Agent 或生效页选择整组，预览展开结果。

**反馈与结果**：相同成员不能重复添加。

## 数据范围

组说明、成员引用与作用。

## 边界情况与异常处理

- 已删除或软件不匹配的成员阻止保存与生效；已有组仍可编辑修复。
- 相同 Hook 出现在多个组不重复部署。

## 验收条件

- 相同成员不能重复添加。
- 从一个组移除成员但另一个已选组仍引用时，该 Hook 保留。
