# GitHub资产库连接

类型：概念（Concept） · 状态：当前实现反推 · 核对日期：2026-10-18

## 功能描述

将整个资产库连接到一个 GitHub 仓库，在其他电脑载入资产与完整历史。

## 定位

所属功能包：[[docs/prd/资产管理工作台/资产库远程同步|资产库远程同步]]。本节点为原子能力，引用依赖与层级子节点分开维护。

- [[docs/prd/资产管理工作台/资产库远程同步/GitHub资产库连接|GitHub资产库连接]] [C] ●

## 业务规则与约束

- 连接接受受支持的 GitHub 仓库地址，使用系统 Git 凭据，不由应用保存令牌。
- 连接使用远程默认分支；远端为空时可用于现有本地资产。
- 新本机资产库为空且只有初始化历史时，可载入远端现有资产。
- 双方是无共同来源的独立历史时不自动合并，提示使用空仓库连接已有本地资产。
- 本功能管理全库资产，不包含 Plugins 独立仓库与本机私有信息。

## 交互流程和细节

**前置条件**：应用已启动，用户进入上述功能入口；涉及已有资产时先选择资产。其余前置能力见下方引用。

1. 进入远程同步，填写 GitHub 仓库链接并连接。
2. 查看连接状态和当前分支。
3. 首次在另一电脑连接后分配本机项目路径和模型密钥。

**反馈与结果**：空本机连接现有仓库后能看到资产与历史。

## 数据范围

全库资产历史、远程地址、同步分支及本机连接状态。

## 边界情况与异常处理

- 无效地址、凭据或网络失败显示错误。
- 连接不同历史的失败可能已修改本机远程关联，需核对连接状态后处理。

## 验收条件

- 空本机连接现有仓库后能看到资产与历史。
- 原电脑项目路径和密钥不随连接载入。
