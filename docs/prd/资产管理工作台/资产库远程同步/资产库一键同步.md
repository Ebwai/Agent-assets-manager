# 资产库一键同步

类型：概念（Concept） · 状态：当前实现反推 · 核对日期：2026-10-18

## 功能描述

根据本机和远端进度接收、推送或合并资产版本。

## 定位

所属功能包：[[docs/prd/资产管理工作台/资产库远程同步|资产库远程同步]]。本节点为原子能力，引用依赖与层级子节点分开维护。

- [[docs/prd/资产管理工作台/资产库远程同步/资产库一键同步|资产库一键同步]] [C] ●

## 业务规则与约束

- 同步前要求已连接、无未提交资产仓库文件、无待解冲突，并执行私有历史检查。
- 本机领先时推送，远端领先时接收，双方有新提交时尝试合并；不自动强制推送。
- 可自动合并的内容同步后更新状态；冲突转入逐项选择流程。
- 同步不自动向目标项目部署，不同步本机路径、密钥、MCP 环境变量、问题记录及历史选用状态。

## 交互流程和细节

**前置条件**：应用已启动，用户进入上述功能入口；涉及已有资产时先选择资产。其余前置能力见下方引用。

1. 打开远程同步，查看状态后点击一键同步。
2. 等待完成；若列出冲突，则逐项处理。
3. 完成后检查资产，需要时在项目再次生效。

**反馈与结果**：两个有共同历史的电脑可分别产生版本并同步。

## 数据范围

全库可同步资产与 Git 历史。

## 边界情况与异常处理

- 网络、认证或推送失败显示原因，不能当作同步成功。
- 存在未提交文件先要求处理，避免把不明确修改带入同步。

## 验收条件

- 两个有共同历史的电脑可分别产生版本并同步。
- 同步后目标项目文件不自动变化。
