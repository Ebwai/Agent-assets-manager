# 项目当前配置查看

类型：概念（Concept） · 状态：当前实现反推 · 核对日期：2026-10-18

## 功能描述

查看本机项目已写入的资产、版本和文件状态。

## 定位

所属功能包：[[docs/prd/资产管理工作台/项目资产接入|项目资产接入]]。本节点为原子能力，引用依赖与层级子节点分开维护。

- [[docs/prd/资产管理工作台/项目资产接入/项目当前配置查看|项目当前配置查看]] [C] ●

## 业务规则与约束

- 分别展示 Claude Code 与 Codex 的生效记录、应用时间、模型、资产、工具和 MCP 名称。
- 显示生效版本、当前资产是否被删除或有更新；不把默认关联当作已应用。
- 文件可标识一致、修改、缺失、无效或未验证；列出项目内非助手管理的 Rules。
- 不展示 API Key 和 MCP 环境变量；旧记录缺失的 Agent、模型或版本标为未知。
- 视图不能证明目标软件已重新加载，不包含用户级配置。

## 交互流程和细节

**前置条件**：应用已启动，用户进入上述功能入口；涉及已有资产时先选择资产。其余前置能力见下方引用。

1. 在项目中选择已分配目录的项目。
2. 查看当前配置资产，点击刷新。
3. 检查所用版本与文件状态，按需到资产编辑或生效页处理。

**反馈与结果**：默认关联但未生效的资产不显示成已应用。

## 数据范围

本机项目生效记录、当前实际文件、当前资产库及外部规则路径。

## 边界情况与异常处理

- 某软件记录损坏时显示该软件错误，另一软件仍可显示。
- 旧记录未提供的信息不推断为已验证。

## 验收条件

- 默认关联但未生效的资产不显示成已应用。
- 手动修改或删除管理文件后，刷新显示对应状态。
