# 项目原生资产识别导入

类型：概念（Concept） · 状态：当前实现反推 · 核对日期：2026-10-18

## 功能描述

只读扫描项目现有指令、Skills、Rules、Agent 和命令 Hooks，并逐项确认入库。

## 定位

所属功能包：[[docs/prd/资产管理工作台/项目资产接入|项目资产接入]]。本节点为原子能力，引用依赖与层级子节点分开维护。

- [[docs/prd/资产管理工作台/项目资产接入/项目原生资产识别导入|项目原生资产识别导入]] [C] ●

## 业务规则与约束

- 扫描项目级标准位置：根目录及 Claude 项目指令，Claude/Agents/Codex Skill 目录，Claude Rules/Agent，Claude 设置和 Codex Hooks 配置。
- 扫描不执行脚本、不改写原文件、不自动登记资产；已由助手管理的内容排除。
- 同一项目和来源路径下，已确认的相同内容不重复导入；源变更后重新待确认。跳过项可重新查看。
- 遇到同类型同名资产，先展示差异，再选择改名入库或登记为已有资产的新版本；保留旧历史。
- 确认时来源或既有资产已变化，拒绝旧预览，要求重新识别；可选关联模型。
- 扫描上限为 3000 个文件、500 个资产、64 MB 内容，Skill 资源最多 12 MB；不跟随链接或读取项目外、用户级配置。

## 交互流程和细节

**前置条件**：应用已启动，用户进入上述功能入口；涉及已有资产时先选择资产。其余前置能力见下方引用。

1. 选择项目目录；新项目首次保存后开始识别，已有项目可识别/继续确认。
2. 逐项查看来源、正文、配置和资源；修改名称、可选模型、版本说明。
3. 处理同名差异并确认、跳过或稍后继续；从项目页恢复后续确认。

**反馈与结果**：扫描前后来源文件不变且资产数量不因扫描增加。

## 数据范围

允许位置的本机项目原生资产，以及本机导入确认/跳过记录。

## 边界情况与异常处理

- 不支持原生 Agent 字段或 Hook 类型提示未转换，不能作为完整备份。
- 外部脚本不随命令 Hook 自动复制；导入后不自动关联或重新部署。

## 验收条件

- 扫描前后来源文件不变且资产数量不因扫描增加。
- 同名内容可改名导入或保存为新版本，旧预览变更后无法确认。
