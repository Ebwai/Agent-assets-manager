# 本机私有信息隔离

类型：机制（Mechanism） · 状态：当前实现反推 · 核对日期：2026-10-18

## 功能描述

区分可跨电脑共享资产与只属于当前电脑的设置和使用状态。

## 定位

所属功能包：[[docs/prd/资产管理工作台/公共支撑能力|公共支撑能力]]。本节点为原子能力，引用依赖与层级子节点分开维护。

- [[docs/prd/资产管理工作台/公共支撑能力/本机私有信息隔离|本机私有信息隔离]] [M] ●

## 业务规则与约束

- 项目路径、模型密钥、MCP 环境变量、本机历史选用、问题记录和导入决策不进入全库同步资产。
- 新电脑需要重新分配路径、密钥和本机环境变量；历史选用只在本机影响读取。
- 模型 Key 以本机明文文件保存，应用不宣称加密保管；GitHub 凭据交由系统 Git 管理。
- 资产数据移至用户目录 Agent_assets_manager；首次启动可从旧 .asset-data 迁移资产及完整历史。
- 本地网页默认可被同局域网访问，没有分角色权限隔离，访客具完整操作能力；当前产品适用于可信使用环境。

## 交互流程和细节

**前置条件**：由上层产品动作触发；相关输入与本机状态需满足下列规则。

1. 启动时载入或迁移资产及本机设置。
2. 上层保存资产时将私有信息保留在当前电脑。
3. 同步或包快照操作仅取允许共享的内容。

**反馈与结果**：同步后另一电脑看到项目名称但看不到原目录。

## 数据范围

可共享资产，以及各类本机私有信息和操作状态。

## 前置能力

无独立前置功能包；由所属上层能力触发。

## 边界情况与异常处理

- 此隔离不等于清理旧历史；历史含私有内容需先检查并处理。
- 迁移不代表为另一电脑自动补齐本机配置。

## 验收条件

- 同步后另一电脑看到项目名称但看不到原目录。
- 本机问题及历史选用不改变远端资产。
