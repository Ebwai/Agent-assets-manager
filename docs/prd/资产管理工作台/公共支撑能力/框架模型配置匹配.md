# 框架模型配置匹配

类型：机制（Mechanism） · 状态：当前实现反推 · 核对日期：2026-10-18

## 功能描述

让同一 Skill、套件、提示词或 Agent 按框架与模型保存不同微调内容。

## 定位

所属功能包：[[docs/prd/资产管理工作台/公共支撑能力|公共支撑能力]]。本节点为原子能力，引用依赖与层级子节点分开维护。

- [[docs/prd/资产管理工作台/公共支撑能力/框架模型配置匹配|框架模型配置匹配]] [M] ●

## 业务规则与约束

- 配置组合由 Harness 框架和已登记模型版本共同确定；新建编辑上述资产先选择组合。
- 同一资产可保存多个组合，保存当前组合时保留其他已有组合。
- 生效时精确匹配目标组合，缺失配置拒绝应用，不静默套用另一模型的内容。
- 未配置组合的旧版或原生导入资产可保留原内容；后续编辑按当前编辑器规则选择组合。
- Hooks、Hooks 组、Rules 不参与模型组合。

## 交互流程和细节

**前置条件**：由上层产品动作触发；相关输入与本机状态需满足下列规则。

1. 上层在编辑时选择框架和模型，并保存该组合内容。
2. 切换组合读取或编辑对应配置。
3. 生效解析时检查所选资产及引用成员的组合是否存在。

**反馈与结果**：两个组合各自保存不同内容，切换及生效取到对应值。

## 数据范围

框架、模型服务引用、资产各组合的内容快照。

## 前置能力

无独立前置功能包；由所属上层能力触发。

## 边界情况与异常处理

- 模型已删除、组合不完整或选择了未配置组合时显示原因。
- 提示词适用对象与组合冲突不能保存。

## 验收条件

- 两个组合各自保存不同内容，切换及生效取到对应值。
- 未配置第三个组合时生效报错。
