# 同步前私有历史检查

类型：机制（Mechanism） · 状态：当前实现反推 · 核对日期：2026-10-18

## 功能描述

在上传全库历史前阻止已知旧版私有信息泄露。

## 定位

所属功能包：[[docs/prd/资产管理工作台/公共支撑能力|公共支撑能力]]。本节点为原子能力，引用依赖与层级子节点分开维护。

- [[docs/prd/资产管理工作台/公共支撑能力/同步前私有历史检查|同步前私有历史检查]] [M] ●

## 业务规则与约束

- 连接仓库和执行同步前检查项目、Agent 的历史内容。
- 历史发现本机项目路径或非空 MCP 环境变量时停止同步，提示迁移或清理历史。
- 不自动重写用户历史，不宣称扫描任意正文中的所有秘密。

## 交互流程和细节

**前置条件**：由上层产品动作触发；相关输入与本机状态需满足下列规则。

1. 上层发起连接或同步时自动执行检查。
2. 无已知问题则继续；发现时显示具体类别和处理要求。

**反馈与结果**：仅在历史存在的项目路径也能阻止同步。

## 数据范围

全库项目与 Agent 历史版本中的已知私有字段。

## 前置能力

无独立前置功能包；由所属上层能力触发。

## 边界情况与异常处理

- 当前版本已去除敏感字段但旧历史仍存在时依然阻止。
- 问题处理完成后用户重新发起同步。

## 验收条件

- 仅在历史存在的项目路径也能阻止同步。
- 检查失败不进行后续上传。
