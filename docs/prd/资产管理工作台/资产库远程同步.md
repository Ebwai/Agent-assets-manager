# 资产库远程同步

类型：概念（Concept） · 状态：当前实现反推

## 功能描述

在多台电脑之间共享全库资产及历史，并由用户处理内容冲突。

## 业务规则与约束

只共享允许同步的数据；先检查私有历史，再按进度同步，有冲突逐项选择一侧。

- [[docs/prd/资产管理工作台/资产库远程同步/GitHub资产库连接|GitHub资产库连接]]：将整个资产库连接到一个 GitHub 仓库，在其他电脑载入资产与完整历史。
- [[docs/prd/资产管理工作台/资产库远程同步/资产库一键同步|资产库一键同步]]：根据本机和远端进度接收、推送或合并资产版本。
- [[docs/prd/资产管理工作台/资产库远程同步/同步冲突逐项选择|同步冲突逐项选择]]：在全库同步冲突时，由用户对每个冲突选择本机或远端内容。

## 交互流程和细节

**前置条件**：应用已启动；各子能力的具体入口、前置条件及反馈见对应文档。

用户连接 GitHub 仓库并一键同步，遇到冲突时完成所有选择后继续。

**用户可观察结果**：完成对应子能力的操作后，获得该子能力定义的内容、记录或错误反馈；父功能包不增加额外隐含操作。

## 数据范围

全库资产与历史，不含 Plugins 独立仓库和本机私有信息。

以上为下属能力使用的外部引用汇总，并非进入整个父功能包必须一次配置全部依赖；按具体操作按需满足。

## 边界情况与异常处理

不同来源的独立历史不自动合并，失败显示原因。

各子能力的限制和异常结果由其节点定义；组合使用时同时遵循必要引用节点的规则。
