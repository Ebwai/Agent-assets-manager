# 问题记录与版本关联

类型：概念（Concept） · 状态：当前实现反推 · 核对日期：2026-10-18

## 功能描述

为每个已保存资产记录本机待办问题，并追溯哪些版本包含了完成结果。

## 定位

所属功能包：[[docs/prd/资产管理工作台/资产版本与问题跟踪|资产版本与问题跟踪]]。本节点为原子能力，引用依赖与层级子节点分开维护。

- [[docs/prd/资产管理工作台/资产版本与问题跟踪/问题记录与版本关联|问题记录与版本关联]] [C] ●

## 业务规则与约束

- 问题为非空自由文本，最多 10000 字，可编辑、删除、完成或重新打开。
- 新增问题不需要版本说明、不创建资产版本；记录发现时本机选用的资产版本。
- 保存版本时列出已完成且尚未纳入当前完成轮次的问题；用户逐项选择，可把文字追加到多行说明。
- 只有版本提交成功才记录所选问题与提交的关联，并保存当时问题文字、完成时间和说明；未选项保留。
- 重新打开再完成可关联新版本并保留旧关联；历史选用、删除恢复不回退问题。
- 问题仅本机保存；编辑时发现已被其他操作修改，要求刷新后再操作。

## 交互流程和细节

**前置条件**：应用已启动，用户进入上述功能入口；涉及已有资产时先选择资产。其余前置能力见下方引用。

1. 资产首次保存后进入待解决问题，输入想法或问题。
2. 按实际进展编辑或勾选完成。
3. 保存资产版本时选取已完成问题、补充版本说明并确认。
4. 查看对应版本记录；需要再次处理时重新打开。

**反馈与结果**：问题增删改不增加资产 Git 版本。

## 数据范围

各资产独立的问题正文、状态、发现版本、历史关联快照。

## 前置能力

- ⇢ [[docs/prd/资产管理工作台/公共支撑能力/本机私有信息隔离|本机私有信息隔离]]

## 边界情况与异常处理

- 新资产未保存不能记录；取消保存或提交失败不关联版本。
- 问题已变化的旧操作不覆盖新内容。

## 验收条件

- 问题增删改不增加资产 Git 版本。
- 重新完成后可关联第二版本，第一关联文字仍保留。
