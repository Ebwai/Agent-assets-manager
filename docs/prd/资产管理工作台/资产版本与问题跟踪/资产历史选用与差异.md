# 资产历史选用与差异

类型：概念（Concept） · 状态：当前实现反推 · 核对日期：2026-10-18

## 功能描述

查看资产历史变化，并为本机选择所需历史版本。

## 定位

所属功能包：[[docs/prd/资产管理工作台/资产版本与问题跟踪|资产版本与问题跟踪]]。本节点为原子能力，引用依赖与层级子节点分开维护。

- [[docs/prd/资产管理工作台/资产版本与问题跟踪/资产历史选用与差异|资产历史选用与差异]] [C] ●

## 业务规则与约束

- 版本历史展示说明、时间与版本标识，可查看差异、在本机使用或恢复使用最新版。
- 在本机使用只改变当前电脑的资产内容，不创建提交、不自动生效、不改变其他电脑。
- 差异比较所选资产版本与它前一个资产版本，跳过无关资产提交；首次版本视为新增。
- 只列变化文件和配置项；Skill 正文与资源分开，红色删除、绿色新增、行内高亮，未变化上下文可展开并可跳转变化。

## 交互流程和细节

**前置条件**：应用已启动，用户进入上述功能入口；涉及已有资产时先选择资产。其余前置能力见下方引用。

1. 打开资产版本历史，选择查看差异。
2. 检查变化内容后返回历史，点击在本机使用。
3. 需要恢复最新版时点击使用最新版本；需修改时编辑并另存版本。

**反馈与结果**：无关资产插入提交后，前后差异仍针对同一资产。

## 数据范围

资产历史、所选版本、前一个资产版本、本机选用状态。

## 前置能力

- ⇢ [[docs/prd/资产管理工作台/公共支撑能力/本机私有信息隔离|本机私有信息隔离]]

## 边界情况与异常处理

- 版本不属于资产或无法读取时拒绝操作。
- 选用旧版本不会回退本机问题记录。

## 验收条件

- 无关资产插入提交后，前后差异仍针对同一资产。
- 选用历史版本后 Git 历史数量不增加，当前内容切换。
