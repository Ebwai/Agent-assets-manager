# 模型辅助迭代

类型：概念（Concept） · 状态：当前实现反推

## 功能描述

通过用户配置模型为已保存 Skill 生成审查意见或问题改进建议。

## 业务规则与约束

模型建议不会自动发布成资产；用户审阅、应用到草稿和保存是独立动作。

- [[docs/prd/资产管理工作台/模型辅助迭代/模型服务配置|模型服务配置]]：配置用于助手 AI 功能的多协议文本模型服务，并可复用为 Claude Code / Codex 自定义 API。
- [[docs/prd/资产管理工作台/模型辅助迭代/Skill模型审查|Skill模型审查]]：调用用户配置模型，对已保存 Skill 给出审查意见。
- [[docs/prd/资产管理工作台/模型辅助迭代/Skill问题驱动改进|Skill问题驱动改进]]：根据问题描述生成改进建议，可把可解析方案带回编辑器审阅。

## 交互流程和细节

**前置条件**：应用已启动；各子能力的具体入口、前置条件及反馈见对应文档。

用户配置模型服务，在 Skill 中选择审查或描述问题生成改进建议。

**用户可观察结果**：完成对应子能力的操作后，获得该子能力定义的内容、记录或错误反馈；父功能包不增加额外隐含操作。
