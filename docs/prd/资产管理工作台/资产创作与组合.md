## 业务规则与约束

分别维护 Skill、套件、提示词、Agent 与 Claude Rules，组合引用不等于复制源资产。

- [[docs/prd/资产管理工作台/资产创作与组合/Skill内容与资源编辑|Skill内容与资源编辑]]：维护单个可复用 Skill 的说明、目标模板、正文及配套资源。
- [[docs/prd/资产管理工作台/资产创作与组合/Skill本地导入|Skill本地导入]]：将已有 SKILL.md 或单个 Skill 目录转换为可编辑资产。
- [[docs/prd/资产管理工作台/资产创作与组合/Skills套件组合|Skills套件组合]]：用共同用途和成员定位把多个现有 Skill 组合为可复用套件。
- [[docs/prd/资产管理工作台/资产创作与组合/分层提示词管理|分层提示词管理]]：维护通用、模型、Harness 框架和项目四类系统提示词。
- [[docs/prd/资产管理工作台/资产创作与组合/Agent配置组合|Agent配置组合]]：把专属指令、Skills、套件、提示词、Hooks、Rules、工具和 MCP 组合为 Agent 配置。
- [[docs/prd/资产管理工作台/资产创作与组合/Claude规则编辑|Claude规则编辑]]：维护 Claude Code 项目行为规范及其适用文件范围。
- [[docs/prd/资产管理工作台/资产创作与组合/Claude规则导入|Claude规则导入]]：从已有 Markdown 规则提取正文和适用范围后登记资产。

## 交互流程和细节

**前置条件**：应用已启动；各子能力的具体入口、前置条件及反馈见对应文档。

用户从资产库进入对应编辑器，检查内容后保存版本，再到项目生效。

**用户可观察结果**：完成对应子能力的操作后，获得该子能力定义的内容、记录或错误反馈；父功能包不增加额外隐含操作。

## 边界情况与异常处理

各子能力的限制和异常结果由其节点定义；组合使用时同时遵循必要引用节点的规则。
