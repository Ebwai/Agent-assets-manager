# 公共支撑能力

类型：机制（Mechanism） · 状态：当前实现反推

## 功能描述

为多个产品分支统一提供组合匹配、私有信息隔离及历史检查。

## 业务规则与约束

公共机制只定义一次，其他节点通过引用使用；私有隔离不代表自动净化历史或通用秘密检测。

- [[docs/prd/资产管理工作台/公共支撑能力/框架模型配置匹配|框架模型配置匹配]]：让同一 Skill、套件、提示词或 Agent 按框架与模型保存不同微调内容。
- [[docs/prd/资产管理工作台/公共支撑能力/本机私有信息隔离|本机私有信息隔离]]：区分可跨电脑共享资产与只属于当前电脑的设置和使用状态。
- [[docs/prd/资产管理工作台/公共支撑能力/同步前私有历史检查|同步前私有历史检查]]：在上传全库历史前阻止已知旧版私有信息泄露。

## 交互流程和细节

**前置条件**：应用已启动；各子能力的具体入口、前置条件及反馈见对应文档。

由编辑、读取、生效、连接或同步操作按需触发，并返回上层可见的内容或错误。

**用户可观察结果**：完成对应子能力的操作后，获得该子能力定义的内容、记录或错误反馈；父功能包不增加额外隐含操作。

## 数据范围

资产组合、共享范围、本机设置及相关历史。

## 前置能力

无独立前置功能包；由所属上层能力触发。

以上为下属能力使用的外部引用汇总，并非进入整个父功能包必须一次配置全部依赖；按具体操作按需满足。

## 边界情况与异常处理

组合缺失明确阻止，已知私有历史问题阻止上传。

各子能力的限制和异常结果由其节点定义；组合使用时同时遵循必要引用节点的规则。
