# 生效资产选择与展开

类型：概念（Concept） · 状态：当前实现反推 · 核对日期：2026-10-18

## 功能描述

为目标项目选择框架、模型和所需资产，形成一次生效组合。

## 定位

所属功能包：[[docs/prd/资产管理工作台/项目配置生效|项目配置生效]]。本节点为原子能力，引用依赖与层级子节点分开维护。

- [[docs/prd/资产管理工作台/项目配置生效/生效资产选择与展开|生效资产选择与展开]] [C] ●

## 业务规则与约束

- 可选择 Agent、单个 Skills、套件、提示词、Hooks、Hooks 组、Claude Rules。
- 展开 Agent、套件和组引用，对同一资产去重；套件成员按各自本机选用版本和目标组合匹配。
- 默认套件与 Rules 可由项目带入；显式选择覆盖对应默认选择。
- Hooks/Rules 不绑定模型，可单独应用；需框架模型组合的资产缺少匹配配置时拒绝。
- 同次生效的 Skill 名称冲突、缺失引用、软件不匹配均阻止继续。

## 交互流程和细节

**前置条件**：应用已启动，用户进入上述功能入口；涉及已有资产时先选择资产。其余前置能力见下方引用。

1. 进入生效页，选择项目和 Claude Code 或 Codex。
2. 按需求选择模型、Agent、独立资产和组合资产。
3. 查看可用项，进入预览并修复缺失或不匹配。

**反馈与结果**：重复来源引用的 Skill/Hook 只出现一次。

## 数据范围

项目默认选择、用户本次选择、Agent/套件/组引用、各资产本机选用内容。

## 边界情况与异常处理

- 完全未选择有效资产且无待撤销 Hooks/Rules 时提示选择资产。
- 被删除引用不会静默忽略。

## 验收条件

- 重复来源引用的 Skill/Hook 只出现一次。
- 选择不匹配模型的资产时预览失败并提示配置缺失。
