# 配置预览与确认写入

类型：概念（Concept） · 状态：当前实现反推 · 核对日期：2026-10-18

## 功能描述

先展示目标文件和移除项，用户确认后将组合写入项目。

## 定位

所属功能包：[[docs/prd/资产管理工作台/项目配置生效|项目配置生效]]。本节点为原子能力，引用依赖与层级子节点分开维护。

- [[docs/prd/资产管理工作台/项目配置生效/配置预览与确认写入|配置预览与确认写入]] [C] ●

## 业务规则与约束

- 预览展示目标路径、文本内容、二进制说明、移除项和提示词层；预览不写项目文件。
- Claude Skill 写入 .claude/skills，Codex 写入 .agents/skills；指令分别写入 CLAUDE.md 或 AGENTS.md。
- 写入指令时覆盖整个文件，预览标示覆盖全部内容，旧管理区块及区块外原文都替换；重复生效不追加。
- Claude 工具写入允许清单、MCP 写入项目 MCP 配置；Codex 工具以指令表达、MCP 写入 Codex 项目配置。
- Rules/Hooks 按所属项目级位置合并；只应用 Rules 按 Rules 范围处理。
- 成功后记录本次资产版本与文件；用户需在目标软件重新加载，Hook 信任由目标软件处理。
- 一键生效预览基于项目已应用资产与本次增量操作；确认时若资产或项目文件自预览后变化，要求重新预览。成功后清空本次操作并重新读取应用状态。

## 交互流程和细节

**前置条件**：应用已启动，用户进入上述功能入口；涉及已有资产时先选择资产。其余前置能力见下方引用。

1. 完成资产选择后点击预览。
2. 查看将写入和移除的文件，特别确认指令文件的整体覆盖。
3. 点击确认生效；成功后查看反馈和当前配置视图。

**反馈与结果**：预览前后项目文件不变。

## 边界情况与异常处理

- 项目目录无效、已有共享配置格式不正确等情况报告错误。
- 写入包含多个文件；现有实现未提供跨文件失败时的整体回滚保证，失败后需检查项目状态。

## 验收条件

- 预览前后项目文件不变。
- 确认后文件与预览相符，重复生效不重复添加 Hooks。
