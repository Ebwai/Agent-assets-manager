# 项目配置生效

类型：概念（Concept） · 状态：当前实现反推

## 功能描述

将选定资产组合预览并写入 Claude Code 或 Codex 的项目配置。

## 业务规则与约束

先选目标和资产再预览确认；精确匹配组合、引用展开和管理内容保护共同生效。

- [[docs/prd/资产管理工作台/项目配置生效/生效资产选择与展开|生效资产选择与展开]]：为目标项目选择框架、模型和所需资产，形成一次生效组合。
- [[docs/prd/资产管理工作台/项目配置生效/配置预览与确认写入|配置预览与确认写入]]：先展示目标文件和移除项，用户确认后将组合写入项目。
- [[docs/prd/资产管理工作台/项目配置生效/已管配置更新与保护|已管配置更新与保护]]：在再次生效时更新或撤销助手管理内容，并保护特定外部配置与手工修改。

## 交互流程和细节

**前置条件**：应用已启动；各子能力的具体入口、前置条件及反馈见对应文档。

用户选择项目和框架，选择资产，检查预览后确认写入。

**用户可观察结果**：完成对应子能力的操作后，获得该子能力定义的内容、记录或错误反馈；父功能包不增加额外隐含操作。

## 数据范围

本次选择、目标文件、移除项和本机生效记录。

## 边界情况与异常处理

指令文件整体覆盖；其他文件按所属保护策略处理，不能泛化为全部保留手工内容。

各子能力的限制和异常结果由其节点定义；组合使用时同时遵循必要引用节点的规则。
