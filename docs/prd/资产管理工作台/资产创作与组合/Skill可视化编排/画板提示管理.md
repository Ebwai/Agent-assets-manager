# 画板提示管理

类型：概念（Concept） · 需求确认：2026-10-19

## 功能描述

提示不完整连接、缺失说明及资源等潜在问题，用户可自行决定是否处理。

## 定位

上层：[[docs/prd/资产管理工作台/资产创作与组合/Skill可视化编排|Skill可视化编排]]。

- [[docs/prd/资产管理工作台/资产创作与组合/Skill可视化编排/画板提示管理|画板提示管理]] [C] ●

## 业务规则与约束

- 所有语义问题只提醒，不拦截保存、生成或生效；用户可忽略／移除单条提示。
- 支持查看已忽略提示及重新显示；提示忽略随图保存。
- 缺少分支条件、汇合规则、退出条件、规则对象、资源路径及孤立节点均可继续。
- 数据结构损坏或超出容量不属于语义提示，需要修复才能解析。

## 交互流程和细节

前置：进入 Skill 编辑器；使用 AI 时需已配置可用模型。

查看提示列表 → 点击定位节点 → 修改或移除提示 → 继续保存。

## 数据范围

当前模板画板、正文、资源引用及相关草稿状态。

## 前置能力

- ⇢ [[docs/prd/资产管理工作台/资产创作与组合/Skill内容与资源编辑|Skill内容与资源编辑]]

## 边界情况与异常处理

不完整语义仅提醒；不可解析的结构反馈错误。失败不自动保存版本，保留已编辑草稿。
