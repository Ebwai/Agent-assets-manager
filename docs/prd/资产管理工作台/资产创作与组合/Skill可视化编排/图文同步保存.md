# 图文同步保存

类型：机制（Mechanism） · 需求确认：2026-10-19

## 功能描述

在已有画板的 Skill 中确保文字修改先同步到图，再保存新版本。

## 定位

上层：[[docs/prd/资产管理工作台/资产创作与组合/Skill可视化编排|Skill可视化编排]]。

- [[docs/prd/资产管理工作台/资产创作与组合/Skill可视化编排/图文同步保存|图文同步保存]] [M] ●

## 业务规则与约束

- 直接改图立即生成正文，无需 AI 即可保存。
- 已有图时修改正文，需要主动点击 AI 同步到现有图，成功后才能保存；失败保留草稿。
- 所有带图模板分别检查，切换框架、模型配置或模板不能绕过同步要求。
- 图、正文和忽略提示一起保存和恢复；旧的无图 Skill 不受影响。

## 交互流程和细节

前置：进入 Skill 编辑器；使用 AI 时需已配置可用模型。

直接画图 → 保存；或改文字 → AI 同步 → 检查画板 → 保存版本。

## 数据范围

当前模板画板、正文、资源引用及相关草稿状态。

## 前置能力

- ⇢ [[docs/prd/资产管理工作台/资产创作与组合/Skill内容与资源编辑|Skill内容与资源编辑]]

## 边界情况与异常处理

不完整语义仅提醒；不可解析的结构反馈错误。失败不自动保存版本，保留已编辑草稿。
