# 画板结构与规则编辑

类型：概念（Concept） · 需求确认：2026-10-19

## 功能描述

在统一画板创建、移动、连接、删除步骤及规则卡片，并通过侧栏修改完整文字。

## 定位

上层：[[docs/prd/资产管理工作台/资产创作与组合/Skill可视化编排|Skill可视化编排]]。

- [[docs/prd/资产管理工作台/资产创作与组合/Skill可视化编排/画板结构与规则编辑|画板结构与规则编辑]] [C] ●

## 业务规则与约束

- 节点包含输入、输出、步骤、判断、并行、汇合、等待、循环、验证、子流程和区域；支持全局、节点、连线及区域规则。
- 支持缩放、平移、自动布局、撤销重做、源数据导入导出；节点位置与执行顺序独立。
- Key Points、边界条件、资源与作者便签在同一画板中；便签不进入生成文档。
- 子流程可用区域归属组织并引用，资源引用不执行文件。

## 交互流程和细节

前置：进入 Skill 编辑器；使用 AI 时需已配置可用模型。

进入 Skill → 打开画板 → 添加卡片并连接 → 选中编辑细节 → 查看正文 → 保存。

## 数据范围

当前模板画板、正文、资源引用及相关草稿状态。

## 边界情况与异常处理

不完整语义仅提醒；不可解析的结构反馈错误。失败不自动保存版本，保留已编辑草稿。
