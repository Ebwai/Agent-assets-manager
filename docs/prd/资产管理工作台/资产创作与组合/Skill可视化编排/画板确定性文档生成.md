# 画板确定性文档生成

类型：机制（Mechanism） · 需求确认：2026-10-19

## 功能描述

根据画板内容和连接关系，以固定模板生成 Skill 正文。

## 定位

上层：[[docs/prd/资产管理工作台/资产创作与组合/Skill可视化编排|Skill可视化编排]]。

- [[docs/prd/资产管理工作台/资产创作与组合/Skill可视化编排/画板确定性文档生成|画板确定性文档生成]] [M] ●

## 业务规则与约束

- 生成全程不调用 AI。按稳定步骤引用描述串行、条件、并行、汇合、重复、等待和验证。
- 留空字段由 Agent 结合上下文判断，输入缺失不自动变成必须询问用户。
- 保留非可视化文字及资源路径，节点和区域约束保持原作用范围。
- 布局与提示忽略不影响正文，相同语义产生相同输出。

## 交互流程和细节

前置：进入 Skill 编辑器；使用 AI 时需已配置可用模型。

画板内容变更后实时生成；查看完整 Skill 预览后按现有方式保存或生效。

## 数据范围

当前模板画板、正文、资源引用及相关草稿状态。

- ⇢ [[docs/prd/资产管理工作台/资产创作与组合/Skill内容与资源编辑|Skill内容与资源编辑]]

## 边界情况与异常处理

不完整语义仅提醒；不可解析的结构反馈错误。失败不自动保存版本，保留已编辑草稿。
