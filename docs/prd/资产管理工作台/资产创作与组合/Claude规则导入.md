# Claude规则导入

类型：概念（Concept） · 状态：当前实现反推 · 核对日期：2026-10-18

## 功能描述

从已有 Markdown 规则提取正文和适用范围后登记资产。

## 定位

所属功能包：[[docs/prd/资产管理工作台/资产创作与组合|资产创作与组合]]。本节点为原子能力，引用依赖与层级子节点分开维护。

- [[docs/prd/资产管理工作台/资产创作与组合/Claude规则导入|Claude规则导入]] [C] ●

## 业务规则与约束

- 支持选择一个或多个 .md，或选择 rules 文件夹；先预览并勾选。
- 解析已有 paths；额外 YAML 字段提示目标软件不识别的内容。
- 单条进入编辑器等待保存，多条填写版本说明后逐条保存。

## 交互流程和细节

**前置条件**：应用已启动，用户进入上述功能入口；涉及已有资产时先选择资产。其余前置能力见下方引用。

1. 在 Rules 选择导入文件或目录。
2. 检查解析出的正文、paths 和警告，勾选要导入的规则。
3. 单条编辑后保存，或确认批量导入并填写说明。

**反馈与结果**：带 paths 的规则导入后再次预览保留适用范围。

## 数据范围

用户所选规则文件及 YAML 适用范围。

## 前置能力

- ⇢ [[docs/prd/资产管理工作台/资产创作与组合/Claude规则编辑|Claude规则编辑]]
- ⇢ [[docs/prd/资产管理工作台/资产版本与问题跟踪/资产版本保存|资产版本保存]]

## 边界情况与异常处理

- YAML 非法、文件路径非法或内容无效时反馈原因。
- 导入来源不被改写；不自动改变项目默认关联。

## 验收条件

- 带 paths 的规则导入后再次预览保留适用范围。
- 单条未保存时不新增资产版本。
