# Agent配置组合

类型：概念（Concept） · 状态：当前实现反推 · 核对日期：2026-10-18

## 功能描述

把专属指令、Skills、套件、提示词、Hooks、Rules、工具和 MCP 组合为 Agent 配置。

## 定位

所属功能包：[[docs/prd/资产管理工作台/资产创作与组合|资产创作与组合]]。本节点为原子能力，引用依赖与层级子节点分开维护。

- [[docs/prd/资产管理工作台/资产创作与组合/Agent配置组合|Agent配置组合]] [C] ●

## 业务规则与约束

- Agent 的目标框架为 Claude Code 或 Codex，可保留多个框架与模型组合。
- 可关联单个 Skill、套件、额外提示词、单个 Hook 和 Hooks 组；Rules 仅供 Claude Code。
- MCP 需有名称和启动命令，可配置参数和本机环境变量。
- Claude 工具选择用于预批准配置；Codex 工具选择写为 Agent 指令，不能承诺实际工具权限。

## 交互流程和细节

**前置条件**：应用已启动，用户进入上述功能入口；涉及已有资产时先选择资产。其余前置能力见下方引用。

1. 进入 Agent，选择框架与模型组合。
2. 填写名称、专属指令并选择关联资产、工具和 MCP。
3. 填写版本说明保存；到生效页选择该 Agent 预览。

**反馈与结果**：Claude Agent 可关联 Rules，Codex 不能关联。

## 数据范围

Agent 指令、关联资产、工具名称、MCP 启动信息；环境变量为本机私有信息。

## 边界情况与异常处理

- 关联的 Hook/组不存在或目标不一致时不能保存或生效。
- 关联资产被删除不会自动修复，生效时报告缺失。

## 验收条件

- Claude Agent 可关联 Rules，Codex 不能关联。
- 同一 Hook 经 Agent 和组同时引用时只部署一次。
