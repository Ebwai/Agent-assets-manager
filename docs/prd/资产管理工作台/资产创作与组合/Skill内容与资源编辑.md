# Skill内容与资源编辑

类型：概念（Concept） · 状态：当前实现反推 · 核对日期：2026-10-18

## 功能描述

维护单个可复用 Skill 的说明、目标模板、正文及配套资源。

## 定位

所属功能包：[[docs/prd/资产管理工作台/资产创作与组合|资产创作与组合]]。本节点为原子能力，引用依赖与层级子节点分开维护。

- [[docs/prd/资产管理工作台/资产创作与组合/Skill内容与资源编辑|Skill内容与资源编辑]] [C] ●

## 业务规则与约束

- 区分通用、Claude Code、Codex 模板；可编辑 YAML 元信息并预览完整 SKILL.md。
- 通用和 Codex 的 name 为 1–64 位小写字母、数字和连字符，description 为 1–1024 字符；Claude 模板允许省略这两项，但填写时仍校验。正文必须非空。
- compatibility 最多 500 字符；metadata 为字符串键值映射；未知或不适用于当前模板的字段提示校验错误。
- 资源归入 scripts、references、assets；可编辑文本、上传二进制资源、改名和移除；资源路径须在允许范围内。字符计数按非空白字符显示。
- 保存和部署 Skill 均不在助手内执行资源脚本。

## 交互流程和细节

**前置条件**：应用已启动，用户进入上述功能入口；涉及已有资产时先选择资产。其余前置能力见下方引用。

1. 进入单个 Skills 包，新建或选择已有资产。
2. 编辑当前模板的元信息、正文和资源；执行检查或预览，修正提示。
3. 填写版本说明并保存；需要调用模型评估时进入已保存 Skill 的审查或改进入口。

**反馈与结果**：空正文不能保存；合法内容预览包含元信息和正文。

## 可视化扩展（2026-10-19）

正文旁提供统一画板入口及推荐的直接画图修改路径；带图模板的正文改动须先 AI 同步再保存。画板规则及语义提醒见 ⇢ [[docs/prd/资产管理工作台/资产创作与组合/Skill可视化编排|Skill可视化编排]]；原有元信息、资源、预览及无图编辑仍可使用。

## 数据范围

Skill 名称、摘要、各模板元信息和正文、资源文件。

## 边界情况与异常处理

- 格式不合要求时阻止保存或生效并指出问题。
- 重复资源名不覆盖已有资源；不合法路径拒绝接收。

## 验收条件

- 空正文不能保存；合法内容预览包含元信息和正文。
- 资源编辑后保存版本，生效结果包含对应资源。
