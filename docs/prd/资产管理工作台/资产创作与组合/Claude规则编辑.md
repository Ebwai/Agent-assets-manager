# Claude规则编辑

类型：概念（Concept） · 状态：当前实现反推 · 核对日期：2026-10-18

## 功能描述

维护 Claude Code 项目行为规范及其适用文件范围。

## 定位

所属功能包：[[docs/prd/资产管理工作台/资产创作与组合|资产创作与组合]]。本节点为原子能力，引用依赖与层级子节点分开维护。

- [[docs/prd/资产管理工作台/资产创作与组合/Claude规则编辑|Claude规则编辑]] [C] ●

## 业务规则与约束

- Rules 不绑定模型，仅支持 Claude Code；文件名为不含目录和系统保留字符的 .md 名。
- 正文非空且最多 200000 字节，不允许把 YAML 头直接写入正文。
- 适用范围为项目内相对 glob，每行一条，最多 100 条，每条最长 500 字符；留空表示全项目。
- 输出时根据适用范围生成 paths 元信息。当前类别不提供搜索、分类或模板。

## 交互流程和细节

**前置条件**：应用已启动，用户进入上述功能入口；涉及已有资产时先选择资产。其余前置能力见下方引用。

1. 进入 Rules，新建规则，填写名称、文件名、正文及适用文件。
2. 检查与预览规则，修正问题。
3. 保存后由项目默认、Agent 关联或生效页直接选择。

**反馈与结果**：空范围的规则预览为全项目规则。

## 数据范围

规则正文、规则文件名和文件匹配范围。

## 前置能力

- ⇢ [[docs/prd/资产管理工作台/资产版本与问题跟踪/资产版本保存|资产版本保存]]

## 边界情况与异常处理

- 绝对路径、上级目录和非法文件名被拒绝。
- 只应用 Rules 按规则范围更新，不把它当作系统提示词正文。

## 验收条件

- 空范围的规则预览为全项目规则。
- 无效 glob 路径或 YAML 正文提示具体错误。
