# Skills套件组合

类型：概念（Concept） · 状态：当前实现反推 · 核对日期：2026-10-18

## 功能描述

用共同用途和成员定位把多个现有 Skill 组合为可复用套件。

## 定位

所属功能包：[[docs/prd/资产管理工作台/资产创作与组合|资产创作与组合]]。本节点为原子能力，引用依赖与层级子节点分开维护。

- [[docs/prd/资产管理工作台/资产创作与组合/Skills套件组合|Skills套件组合]] [C] ●

## 业务规则与约束

- 套件至少包含一个现有 Skill，同一成员不能重复。
- 新版套件必须填写用途及每个成员在套件中的定位和作用。
- 成员顺序不定义固定执行顺序；生效展开全部成员并写入套件说明。

## 交互流程和细节

**前置条件**：应用已启动，用户进入上述功能入口；涉及已有资产时先选择资产。其余前置能力见下方引用。

1. 进入多个 Skills 联动套件，新建套件并填写名称和用途。
2. 添加现有 Skill，逐个说明定位与作用。
3. 选择框架模型组合，保存版本；在项目或 Agent 中引用套件。

**反馈与结果**：重复成员被拒绝。

## 数据范围

套件说明、成员 Skill 引用及成员作用。

## 边界情况与异常处理

- 已删除成员不能保存或生效，提示修复引用。
- 套件定义不复制成员资源；新增或勾选更新套件时，成员当前本机选用版本参与生效。一键生效未操作的套件及成员保留项目原应用版本，单独更新成员不要求重新选择套件。

## 验收条件

- 重复成员被拒绝。
- 套件生效后包含全部成员，指令包含用途和成员作用。
