# Skill可视化编排

类型：概念（Concept） · 需求确认：2026-10-19 用户批注及直接实施授权

## 功能描述

在单个 Skill 中用统一画板编辑执行过程、规则和资源关系，程序化生成适合 Agent 阅读的正文。推荐直接编辑画板；AI 用于已有文字的可视化及文字变更同步。

## 业务规则与约束

- 输入、输出、步骤、判断、并行、汇合、等待、重复、验证、子流程、区域、Key Points、边界条件、资源、作者便签在同一画板表达；侧栏编辑细节。
- 流程箭头表达执行关系，关联线表达规则归属；全局、步骤、连线及区域范围均可表达。
- 未填写细节允许 Agent 根据上下文判断；检查仅提醒，不自动增加强制询问或停止行为。用户明确配置的条件仍忠实输出。
- 支持多个流程入口、区域及子流程引用；编排用于生成指引，不实际执行 Agent、脚本或资源。
- 图、正文、保留章节、提示忽略状态进入现有资产版本；按模板及框架模型配置隔离。

## 交互流程和细节

选择 Skill → 新建画板或 AI 自动转图 → 拖放节点、连线及编辑卡片 → 查看实时文字及提示 → 保存版本。
已有画板时直接编辑画板是推荐路径；编辑正文后须 AI 同步成功再保存。没有画板的旧 Skill 保持文字编辑方式。

## 数据范围

画板及视图位置、节点内容与关联、保留文字章节及修改建议、生成正文、提示忽略状态。

## 边界情况与异常处理

不要求任意外部 Markdown 无损恢复画板；原文逐段定位暂缓，不标记 AI 推断或要求逐项确认。不适合可视化的内容保留为可编辑文字。

## 验收条件

- 图改文不调用模型；相同语义产生相同文字，移动节点不改变文字。
- 不完整、断线、有循环的图也能生成并保存，问题仅作可移除提醒。
- 文字改动未同步不能保存已有画板版本；AI 失败保留全部编辑内容。
- 画板和正文随历史版本一起恢复，未改造 Skill 不受影响。
