# 事件自动化管理

类型：概念（Concept） · 状态：当前实现反推

## 功能描述

管理项目级事件脚本，支持校验、测试、分组和原生配置接入。

## 业务规则与约束

以目标软件的已支持事件为边界；保存、导入和分组本身不执行脚本，模拟测试会真实执行。

- [[docs/prd/资产管理工作台/事件自动化管理/命令Hook编辑|命令Hook编辑]]：配置目标软件的事件、匹配条件、执行环境和脚本。
- [[docs/prd/资产管理工作台/事件自动化管理/Hook模拟测试|Hook模拟测试]]：通过示例事件真实运行脚本，检查匹配、退出码和输出。
- [[docs/prd/资产管理工作台/事件自动化管理/Hooks分组组合|Hooks分组组合]]：把同一软件、共同用途的多个 Hook 组织为可整体应用的组。
- [[docs/prd/资产管理工作台/事件自动化管理/原生Hook配置导入|原生Hook配置导入]]：从 Claude Code 或 Codex 原生配置中逐项提取可支持的命令 Hook。

## 交互流程和细节

**前置条件**：应用已启动；各子能力的具体入口、前置条件及反馈见对应文档。

用户编辑或导入 Hook，检查/测试后保存，可单选或整组用于项目。

**用户可观察结果**：完成对应子能力的操作后，获得该子能力定义的内容、记录或错误反馈；父功能包不增加额外隐含操作。

## 数据范围

单个 Hook、组引用、测试输入输出及原生配置片段。

## 前置能力

- ⇢ [[docs/prd/资产管理工作台/资产版本与问题跟踪/资产版本保存|资产版本保存]]
- ⇢ [[docs/prd/资产管理工作台/项目资产接入/项目登记与本机路径|项目登记与本机路径]]

以上为下属能力使用的外部引用汇总，并非进入整个父功能包必须一次配置全部依赖；按具体操作按需满足。

## 边界情况与异常处理

未知事件和类型显示原因；运行环境需在执行机器可用。

各子能力的限制和异常结果由其节点定义；组合使用时同时遵循必要引用节点的规则。
