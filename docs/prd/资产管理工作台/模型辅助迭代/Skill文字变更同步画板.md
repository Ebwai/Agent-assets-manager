# Skill文字变更同步画板

类型：概念（Concept） · 需求确认：2026-10-19

## 功能描述

让 AI 根据现有画板和文字修改更新图，并恢复可保存状态。

## 定位

上层：[[docs/prd/资产管理工作台/模型辅助迭代|模型辅助迭代]]。

- [[docs/prd/资产管理工作台/模型辅助迭代/Skill文字变更同步画板|Skill文字变更同步画板]] [C] ●

## 业务规则与约束

- 请求包含现有图、图对应的原正文、编辑后正文、修改信息和资源名称。
- 优先保留未受影响节点的标识与布局，更新受影响步骤和规则，返回可编辑完整图。
- 同步成功用程序生成正文；模型／解析失败、取消或编辑已变化时不覆盖当前草稿。
- 转图与同步提示词可在现有审查配置中维护；复用现有模型服务和本机密钥。

## 交互流程和细节

前置：进入 Skill 编辑器；使用 AI 时需已配置可用模型。

改正文 → 点击 AI 同步到现有图 → 选择模型 → 同步成功 → 保存版本。

## 数据范围

当前模板画板、正文、资源引用及相关草稿状态。

## 边界情况与异常处理

不完整语义仅提醒；不可解析的结构反馈错误。失败不自动保存版本，保留已编辑草稿。
