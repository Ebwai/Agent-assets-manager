# 模型服务配置

类型：概念（Concept） · 状态：R11 已实现 · 核对日期：2026-10-20

## 功能描述

配置用于助手内 AI 功能及目标软件自定义 API 的模型服务，支持多种文本 API 协议。

## 定位

所属功能包：[[docs/prd/资产管理工作台/模型辅助迭代|模型辅助迭代]]。本节点为原子能力，引用依赖与层级子节点分开维护。

- [[docs/prd/资产管理工作台/模型辅助迭代/模型服务配置|模型服务配置]] [C] ●

## 业务规则与约束

- 服务需名称、API 协议、HTTP/HTTPS 地址与模型 ID；支持 Anthropic Messages、OpenAI Chat Completions、OpenAI Responses、Gemini generateContent。旧服务未指定协议时按 Anthropic 处理。
- API Key 单独在本机保存；无需认证的本地服务可选择无需密钥。地址不得嵌入账号、密码或查询参数。
- 服务定义参与资产版本；保存时不填写新密钥可保留已保存密钥。
- 助手内 AI 功能复用所选协议；Chat Completions 可选择服务要求的输出长度参数。
- 可为 Claude Code 和 Codex 分别填写外部兼容网关地址与模型 ID；网关复用本服务密钥，使用不同凭据时另建服务。不内置完整协议转换网关。
- 连接测试可使用未保存草稿及已保存密钥，不创建资产版本；仅验证助手内文本调用，不等同于目标软件流式及工具调用兼容认证。
- 模型调用最多等待 90 秒；显示远端服务错误。

## 交互流程和细节

**前置条件**：应用已启动，用户进入上述功能入口；涉及已有资产时先选择资产。其余前置能力见下方引用。

1. 进入模型服务，选择协议，填写名称、地址、模型 ID 和 Key／无需密钥。
2. 可点击「测试连接」验证草稿；显示成功文本或可处理的错误。
3. 填写版本说明保存，检查已配置密钥状态。
4. 在助手 AI 功能中选择该服务；或进入「应用 / 撤销自定义 API」配置目标软件，见 [[docs/prd/资产管理工作台/项目配置生效/模型API配置生效|模型API配置生效]]。

**反馈与结果**：按所选协议返回文本；请求失败、响应格式错误、空文本及输出截断显示明确错误。

## 边界情况与异常处理

- 地址协议、模型 ID 或密钥缺失时提示处理。
- 换电脑或删除后恢复模型定义，需要重新配置本机密钥。

## 验收条件

- 需要认证但未配置 Key 时拒绝调用；无需认证的本地服务可调用。
- 四种协议正确生成请求并解析文本，既有 Anthropic 配置继续可用。
- 远程同步模型定义不包含 Key。
