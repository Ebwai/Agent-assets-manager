# 模型服务配置

类型：概念（Concept） · 状态：R12 已实现 · 核对日期：2026-10-20

## 功能描述

配置用于助手内 AI 功能及目标软件自定义 API 的模型服务，支持多种文本 API 协议。

## 定位

所属功能包：[[docs/prd/资产管理工作台/模型辅助迭代|模型辅助迭代]]。本节点为原子能力，引用依赖与层级子节点分开维护。

- [[docs/prd/资产管理工作台/模型辅助迭代/模型服务配置|模型服务配置]] [C] ●

## 业务规则与约束

- 每个模型可配置是否支持图片输入，随能力定义保存。Codex 应用须按配置声明图片能力，不能将所有模型统一限制为纯文本。配置页展示“支持模态：文本、图片”，默认同时勾选，文本作为基础模态保留，图片可取消；旧定义缺省同样默认启用，显式关闭优先。配置声明不能赋予供应商本身不具备的视觉能力，修改后需保存并重新应用。

- 每个模型 ID 在模型配置界面维护上下文窗口总容量和是否支持 low / medium / high 多个推理强度，随模型资产保存与同步。应用界面只展示能力，按目标客户端转换，不单独维护另一份能力配置。新模型默认 32768 tokens、不发送推理强度。旧 Codex 应用能力在编辑时带回，保存后成为通用配置。
- Codex 支持逐模型窗口与推理等级目录；Claude Code 的窗口覆盖采用本次映射模型的最小值，并在预览提示进程级及客户端识别限制，家族别名和默认自定义选项声明 effort 能力。配置不提高供应商实际容量。

- 一个供应商／服务维护名称、API 协议、HTTP/HTTPS 地址和多个模型 ID，所有模型共享地址与认证。支持 Anthropic Messages、OpenAI Chat Completions、OpenAI Responses、Gemini generateContent。旧服务未指定协议时按 Anthropic 处理。
- 模型列表可从 API 获取并合并，也可每行一个 ID 手工维护；获取列表不自动保存。服务须从列表中指定一个资产 AI 辅助模型，用于审查、改进、画板及连接测试。
- 旧单模型记录兼容为单元素列表，保留服务身份和已有资产组合引用。
- API Key 单独在本机保存；无需认证的本地服务可选择无需密钥。地址不得嵌入账号、密码或查询参数。
- 服务定义参与资产版本；保存时不填写新密钥可保留已保存密钥。
- 助手内 AI 功能复用所选协议；Chat Completions 可选择服务要求的输出长度参数。
- 可为 Claude Code 和 Codex 分别填写外部兼容网关地址；应用时从已保存列表单独选择目标模型，不改变资产 AI 辅助模型。网关复用本服务密钥，使用不同凭据时另建服务。不内置完整协议转换网关。
- 连接测试可使用未保存草稿及已保存密钥，不创建资产版本；仅验证助手内文本调用，不等同于目标软件流式及工具调用兼容认证。
- 模型调用最多等待 90 秒；显示远端服务错误。

## 交互流程和细节

**前置条件**：应用已启动，用户进入上述功能入口；涉及已有资产时先选择资产。其余前置能力见下方引用。

1. 进入模型服务，选择协议，填写供应商名称、地址和 Key／无需密钥。
2. 点击「从 API 获取模型列表」或手工填写模型 ID，再选择资产 AI 辅助模型；可点击「测试 AI 辅助模型连接」验证草稿。
3. 填写版本说明保存，检查已配置密钥状态。
4. 在助手 AI 功能中选择该服务；或进入「应用 / 撤销用户级 API」，另选目标软件使用的模型，见 [[docs/prd/资产管理工作台/项目配置生效/模型API配置生效|模型API配置生效]]。

**反馈与结果**：按所选协议返回文本；请求失败、响应格式错误、空文本及输出截断显示明确错误。

## 边界情况与异常处理

- 地址协议、模型 ID 或密钥缺失时提示处理。
- 删除当前 AI 辅助模型后必须重新选择；获取失败可继续手工维护模型列表。
- 换电脑或删除后恢复模型定义，需要重新配置本机密钥。

## 验收条件

- 需要认证但未配置 Key 时拒绝调用；无需认证的本地服务可调用。
- 四种协议正确生成请求并解析文本，既有 Anthropic 配置继续可用。
- 获取列表、手工维护、AI 模型选择及外部软件模型选择相互一致；外部选择不修改 AI 模型或资产组合引用。
- 远程同步模型定义不包含 Key。
