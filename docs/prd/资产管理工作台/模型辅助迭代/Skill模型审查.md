# Skill模型审查

类型：概念（Concept） · 状态：当前实现反推 · 核对日期：2026-10-18

## 功能描述

调用用户配置模型，对已保存 Skill 给出审查意见。

## 定位

所属功能包：[[docs/prd/资产管理工作台/模型辅助迭代|模型辅助迭代]]。本节点为原子能力，引用依赖与层级子节点分开维护。

- [[docs/prd/资产管理工作台/模型辅助迭代/Skill模型审查|Skill模型审查]] [C] ●

## 业务规则与约束

- 只对已保存 Skill 提供审查入口，选择具体模板及模型服务。
- 输入为当前本机选用 Skill 的模板内容与资源文件名，不能假定模型读取全部资源正文。
- 审查系统提示可在审查配置中调整。
- 结果展示为建议，不自动修改 Skill 或创建版本。

## 交互流程和细节

**前置条件**：应用已启动，用户进入上述功能入口；涉及已有资产时先选择资产。其余前置能力见下方引用。

1. 打开已保存 Skill，点击 AI 审查。
2. 选择模型并开始，界面显示处理中。
3. 阅读结果，按需回编辑器自行修改并保存。

**反馈与结果**：审查完成后资产历史未新增版本。

## 数据范围

当前保存版本的 Skill 模板、资源名称、审查系统提示及模型回复。

## 前置能力

## 边界情况与异常处理

- 没有模型先提示配置；请求失败显示服务错误。
- 编辑器未保存修改不作为本次已保存内容的替代。

## 验收条件

- 审查完成后资产历史未新增版本。
- 服务错误后按钮恢复可操作状态。
