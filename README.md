# Agent 资产管理助手

本地运行的网页应用。资产库位于用户目录下的 `Agent_assets_manager/repo`，每次保存资产都会创建 Git 提交。首次启动会从旧版项目内的 `.asset-data` 迁移资产库及其完整历史。模型密钥、本机项目路径、MCP 环境变量和本机选用的历史版本保存在 `Agent_assets_manager/private`，不参与 Git 同步。

## 启动

需要 Node.js 20+ 和 Git。Windows 可双击 `启动助手.cmd`（首次运行会安装依赖）；也可以先运行 `npm install`，再运行 `npm start`，打开终端显示的 `http://127.0.0.1:3210`。可用 `PORT` 环境变量改端口。

## 使用

1. 在「项目」里登记项目，点击「选择文件夹」打开系统目录选择窗口。本机目录可稍后分配，且不会上传远程。新电脑载入项目后会显示待分配路径。
2. 创建 Skill、套件、提示词层和 Agent 时，先选择 Harness 框架与模型服务中的模型版本。一个资产可保存多个组合的微调内容，每次保存都填写版本说明。新建 Skill 时可点「从本地目录导入」，选择包含 `SKILL.md` 的单个 Skill 文件夹，确认解析预览后编辑或直接保存为 Git 版本。`scripts/`、`references/`、`assets/` 中的文件会一并带入。
3. 在「模型服务」配置 Anthropic 协议的 API 地址、模型名和 API Key。审查与改进会调用此服务。
4. 在「生效」选择 Harness 框架与模型版本，再选择该组合可用的资产、预览目标文件，确认后写入项目目录。Claude Code 使用 `.claude/skills` 和 `CLAUDE.md`；Codex 使用 `.agents/skills` 和 `AGENTS.md`。
5. 在「远程同步」连接一个 GitHub 仓库，再点「一键同步」。新电脑连接同一仓库会载入资产和完整历史。两台电脑修改同一资产时，页面会要求逐项选择本机或远程内容。

在版本历史中点击「在本机使用」只改变这台电脑的当前资产内容，不会产生提交。编辑后点击「保存版本」才会基于仓库最新提交创建一个新版本。旧版本本身不会被重新提交。

生效过程只更新本助手管理的 Skill 目录和文档区块。若目标位置已有非本助手管理的同名 Skill，会阻止覆盖。Claude Code 的允许工具写入 `.claude/settings.json` 的 `permissions.allow`，MCP 写入项目根目录 `.mcp.json`；Codex 的工具清单作为 Agent 指令，MCP 写入 `.codex/config.toml`。请在目标软件重新加载项目配置。

本应用只监听本机回环地址；请勿将端口对外暴露。API Key 在本地明文文件中保存，目录仅供当前机器使用。GitHub 身份凭据由系统的 Git 凭据管理器处理，本应用不保存 GitHub 令牌。建议使用私有仓库。若旧版资产的 Git 历史曾保存本机路径或 MCP 环境变量，应用会阻止远程同步，以免将历史中的敏感内容上传。
